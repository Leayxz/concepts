## ☸️ Kubernetes - K8S (Minikube)
- Estudo e demonstração prática dos principais conceitos de kubernetes utilizando Minikube em ambiente local.

### 🚀 TECNOLOGIAS UTILIZADAS
- **Python & C#** – Base para integração com Kubernetes;
- **FastAPI & ASP.NET** - Framework para construção de APIs REST;
- **Minikube / Docker** – Containerização dos PODs em ambiente local;

### 🧠 CONCEITOS APLICADOS
- Execução de múltiplas instâncias da aplicação utilizando PODs;
- Gerenciamento de réplicas e auto-recriação de PODs utilizando Deployment;
- Exposição e Load Balancing entre PODs utilizando Service;
- Comunicação entre Service e PODs através de Labels e Selectors;
- Simulação de ambiente cloud utilizando Minikube e Docker;

### 📌 FUNCIONALIDADES
- API simples como demonstração;
- Execução de múltiplos PODs simultaneamente;
- Balanceamento de carga automático;
- Possibilidade de escalar apenas alterando a quantidade de réplicas;
- Recuperação automática de PODs em casos de falha;
